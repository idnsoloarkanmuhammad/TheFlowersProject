# Botanical family data: The Flowers Project v4

Family labels used by the local study filter are based on Kew's Plants of the World Online (POWO). The renderer files remain the source for the project's artwork, display names, and study-specific copy. This file records the taxonomic reference used for each existing study; it does not add claims about habitat, origin, season, or conservation.
